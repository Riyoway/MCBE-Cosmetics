# Web catalog

The web catalog is a Vite application using React, TypeScript and Tailwind CSS v4.

## Setup

```bash
cd web
npm install
npm run design:install
npm run dev
```

`npm run design:install` installs the upstream `resend/design-skills` collection for supported coding agents.

The skill is a design reference, not a runtime dependency. The application must keep MCBE Cosmetics branding and must not use Resend logos or imply that the project is affiliated with Resend.

## Planned browsing features

- Search by cosmetic name
- Category filters for capes, cape physics and wings
- Animated/static filters
- Lightweight animated previews
- Detail pages with pack membership and download links
- Direct links to the matching GitHub Release asset

Keep the browser usable without accounts, ads or popups.
