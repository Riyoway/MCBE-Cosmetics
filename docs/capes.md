# Capes

The cape collection is maintained as five independent Bedrock resource packs.

Target split:

| Pack | Cape entries |
| --- | ---: |
| Cape Cosmetics 1 | 100 |
| Cape Cosmetics 2 | 100 |
| Cape Cosmetics 3 | 100 |
| Cape Cosmetics 4 | 100 |
| Cape Cosmetics 5 | 30 |

The original archive also contains two helper/template folders (`0frames` and `0single`) which are not cape entries and should not be exposed in the final Pack 5 selector.

The maintained player/render definitions target current Bedrock behavior while preserving the original cape attribution. See `THIRD_PARTY.md`.
