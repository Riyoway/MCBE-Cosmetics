# MCBE Cosmetics web

Browser UI for the MCBE Cosmetics catalog.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS v4
- `resend/design-skills` for design guidance

## Setup

```bash
npm install
npm run design:install
npm run dev
```

The design skill is used during development only. It is not bundled into the production site.

Do not use Resend logos or present this project as affiliated with Resend. Use the skill for design quality, hierarchy and visual-system guidance while keeping MCBE Cosmetics its own product.
