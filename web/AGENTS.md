# Web agent instructions

Before substantial UI work, make sure `resend/design-skills` is available:

```bash
npm run design:install
```

Apply the skill intentionally to the MCBE Cosmetics browser: dark-first presentation, sharp hierarchy, restrained surfaces, strong spacing and clear interactive states.

Do not copy Resend logos, wordmarks or branded marketing copy. MCBE Cosmetics must remain visually distinct and must not imply affiliation with Resend.

Prioritize browsing performance. Animated cosmetic previews should be lightweight and loaded lazily.
