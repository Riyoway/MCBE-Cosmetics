# Resend Brand Guidelines

## Core colors

| Name | Hex |
| --- | --- |
| Resend Black | `#000000` |
| Resend White | `#FDFDFD` |

### Semantic colors

| Scale | Background | Foreground | Usage |
| --- | --- | --- | --- |
| Gray | `#16171AEB` | `#FDFEFFA6` | Structure, hierarchy, subtle separation |
| Red | `#FF173F2D` | `#FF9592` | Critical states and irreversible actions |
| Amber | `#FA820022` | `#FFCA16` | Caution and pending states |
| Green | `#22FF991E` | `#46FEA5D4` | Success and completion |
| Blue | `#0077FF3A` | `#70B8FF` | Interactive and informational elements |

## Typography

- Favorit for headings and titles
- Inter for body text
- CommitMono for code
- Domaine Display Narrow for display headlines, never product UI
- Use sentence case for headings, buttons, labels and navigation

## Effects and layout

- Dark-first design philosophy
- Sharp contrast between black and light
- Precision and focus over decoration
- Accent colors communicate state, not style
- Simple, stable, intentional forms
- Glass blur: `backdrop-filter: blur(25px)`
- Use subtle borders and restrained gradients

## MCBE Cosmetics constraint

These guidelines are used as a design reference only. Do not use Resend logos, wordmarks or trademarked identity in the MCBE Cosmetics product UI, and do not imply affiliation with Resend.
